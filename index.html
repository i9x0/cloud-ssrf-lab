What am I looking at? This page runs the lab's real decision logic in your browser — the SSRF input filter, IMDSv2 token check, the least-privilege IAM policy and the detector — so the outcomes match the measured results in the repository. The actual 8-container Docker lab (real network isolation) lives on GitHub and runs locally or on a cloud VM.

How the real lab is built

Eight Docker services on four isolated networks reproduce a cloud account's trust relationships; every component maps to a real AWS service.

Across five configurations (23 SSRF payloads + the full kill chain + 100 legitimate requests each): the undefended baseline leaked all 1,000 records, the SSRF guard alone blocked 23/23 payloads, least privilege cut data loss to 0, and all defences combined blocked everything with 0% false positives.
